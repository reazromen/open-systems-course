System Design — From the Ground Up

Learn how to plan software systems, how their components communicate, and how to keep them reliable as users and data grow. This course starts with the fundamentals and gradually moves toward real-world architecture and hands-on design exercises.

Course plan: 10 modules · 60 planned lessons · practical examples and exercises

Start with Lesson 01 →

Course Curriculum

Module 1 — System Design Fundamentals

What system design is, how clients and servers communicate, and the basics of the internet, HTTP, APIs, and databases.

  1. What Is System Design? — Fundamentals
  2. How Does a Software System Work?
  3. Client, Server, Request, and Response
  4. Internet, IP Addresses, DNS, and Ports
  5. HTTP, HTTPS, and APIs
  6. What Is a Database and Why Do We Need One?

Module 2 — Networking and Communication

TCP and UDP, HTTP methods and status codes, REST and JSON, latency, bandwidth, throughput, and synchronous versus asynchronous communication.

  1. TCP and UDP
  2. HTTP Methods, Status Codes, and Headers
  3. REST APIs and JSON
  4. Latency, Bandwidth, and Throughput
  5. Synchronous and Asynchronous Communication

Module 3 — Database Fundamentals

SQL and relational databases, NoSQL, schemas and data modeling, indexes, transactions and ACID, and choosing between SQL and NoSQL.

  1. SQL and Relational Databases
  2. NoSQL Databases and Their Data Models
  3. Schema Design and Data Modeling
  4. Database Indexes
  5. Transactions and ACID
  6. SQL vs. NoSQL: How to Choose

Module 4 — Core Architecture Components

Monoliths, application servers, reverse proxies, load balancers, caching and Redis, CDNs, file and object storage, and stateless versus stateful design.

  1. Monoliths and Application Architecture
  2. Application Servers and Reverse Proxies
  3. Load Balancers
  4. Caching and Redis
  5. Content Delivery Networks (CDNs)
  6. File Storage and Object Storage
  7. Stateless and Stateful Systems

Module 5 — Scalability and Performance

Vertical and horizontal scaling, bottlenecks, replication, sharding and partitioning, connection pooling, and capacity estimation.

  1. Vertical and Horizontal Scaling
  2. Bottlenecks and Performance Diagnosis
  3. Database Replication
  4. Sharding and Partitioning
  5. Database Connection Pooling
  6. Capacity Estimation

Module 6 — Distributed Systems

Distributed systems, message queues, event-driven architecture, Kafka and RabbitMQ, consistency and availability, CAP, eventual consistency, and distributed transactions.

  1. What Is a Distributed System?
  2. Message Queues and Event-Driven Architecture
  3. Kafka and RabbitMQ
  4. Consistency, Availability, and Partition Tolerance
  5. The CAP Theorem
  6. Eventual Consistency and Distributed Transactions

Module 7 — Microservices

Monoliths versus microservices, API gateways, service discovery, service-to-service communication, retries, timeouts, circuit breakers, and idempotency.

  1. Monoliths vs. Microservices
  2. Defining Service Boundaries
  3. API Gateways
  4. Service Discovery
  5. Service-to-Service Communication

Module 8 — Reliability, Security, and Observability

High availability, fault tolerance, failover, disaster recovery, authentication and authorization, rate limiting, logs, metrics, tracing, backups, and recovery.

  1. High Availability and Fault Tolerance
  2. Failover and Disaster Recovery
  3. Authentication and Authorization
  4. Rate Limiting and Abuse Protection
  5. Logs, Metrics, and Traces
  6. Backups, Recovery, and Operational Readiness

Module 9 — Real-World System Design Projects

Problem analysis, URL shorteners, chat applications, social feeds, notification services, video streaming, and file upload and image storage.

  1. Designing a URL Shortener
  2. Lesson 49 — Designing a Chat Application (coming soon)
  3. Lesson 50 — Designing a Social Feed (coming soon)
  4. Lesson 51 — Designing a Notification Service (coming soon)
  5. Lesson 52 — Video Streaming Architecture (coming soon)
  6. Lesson 53 — File Upload and Image Storage (coming soon)
  7. Lesson 54 — Project Review and Trade-offs (coming soon)

Module 10 — Advanced Architecture and Capstone

End-to-end e-commerce architecture, payment safety, search systems, trade-offs and cost optimization, system design interviews, and a final capstone project.

How to Use This Course

  1. Study the lessons in sequence.
  2. Review the concepts and examples alongside each video.
  3. Answer the practice question at the end of each lesson.
  4. Draw your own architecture diagrams and explain why you chose each design.

The curriculum is planned as a 60-lesson series. Lessons 01–48 are now available; subsequent lessons will be added in batches as they are prepared and reviewed.
