System Design বাংলা — একেবারে বেসিক থেকে

একটি সফটওয়্যার সিস্টেম কীভাবে পরিকল্পনা করতে হয়, কীভাবে তার component-গুলো একসঙ্গে কাজ করে, এবং ব্যবহারকারী ও ডেটা বাড়লে সিস্টেমকে কীভাবে নির্ভরযোগ্য রাখা যায়—এসব শিখুন ধাপে ধাপে। কোর্সটি এমনভাবে সাজানো, যাতে একেবারে শুরু থেকে শেখা যায় এবং শেষে বাস্তব সিস্টেম ডিজাইনের অনুশীলন করা যায়।

মডিউল ১ — System Design-এর ভিত্তি

System Design কী, client/server, request/response, internet, HTTP, API ও database-এর প্রাথমিক ধারণা।

  1. System Design কী? — Fundamentals
  2. একটি Software System কীভাবে কাজ করে?
  3. Client, Server, Request ও Response
  4. Internet, IP, DNS ও Port
  5. HTTP, HTTPS ও API
  6. Database কী এবং কেন দরকার?

মডিউল ২ — Networking & Communication

TCP/UDP, HTTP methods ও status codes, REST/JSON, latency, bandwidth, throughput এবং synchronous/asynchronous communication।

পাঠ ০৭–১১

মডিউল ৩ — Database Fundamentals

SQL/RDBMS, NoSQL, schema ও data modeling, indexes, transactions/ACID এবং SQL বনাম NoSQL নির্বাচন।

পাঠ ১২–১৭

মডিউল ৪ — Core Architecture Components

Monolith, application server, reverse proxy, load balancer, caching/Redis, CDN, file/object storage এবং stateless/stateful architecture।

পাঠ ১৮–২৪

মডিউল ৫ — Scalability & Performance

Vertical ও horizontal scaling, bottleneck, replication, sharding, connection pooling এবং capacity estimation।

পাঠ ২৫–৩০

মডিউল ৬ — Distributed Systems

Partial failure, message queues, event-driven architecture, Kafka/RabbitMQ, consistency, availability, CAP, eventual consistency ও distributed transactions।

পাঠ ৩১–৩৬

মডিউল ৭ — Microservices

Monolith বনাম microservices, API gateway, service discovery, inter-service communication, retries, timeouts, circuit breaker ও idempotency।

পাঠ ৩৭–৪১

মডিউল ৮ — Reliability, Security & Observability

High availability, fault tolerance, failover, disaster recovery, authentication/authorization, rate limiting, logs, metrics, tracing, backup ও recovery।

পাঠ ৪২–৪৭

মডিউল ৯ — Real-world System Design Projects

Problem analysis, URL shortener, chat application, social feed, notification service, video streaming এবং file upload/image storage।

পাঠ ৪৮–৫৪

মডিউল ১০ — Advanced Architecture & Capstone

E-commerce architecture, payment safety, search system, trade-offs, cost optimization, system design interview framework এবং final capstone project।

পাঠ ৫৫–৬০

কীভাবে শিখবেন

  1. প্রতিটি পাঠ ধারাবাহিকভাবে দেখুন।
  2. ভিডিওর পাশাপাশি মূল ধারণা ও উদাহরণ পড়ুন।
  3. প্রতিটি পাঠের শেষে দেওয়া প্রশ্নের উত্তর নিজে লিখুন।
  4. নিজের diagram আঁকুন এবং কেন সেই design বেছে নিয়েছেন তা ব্যাখ্যা করুন।

কোর্সটি ধাপে ধাপে প্রকাশ করা হচ্ছে। বর্তমানে প্রথম দুটি পাঠ প্রকাশিত; পরের পাঠগুলো প্রস্তুত ও যাচাই করে যুক্ত করা হবে।
