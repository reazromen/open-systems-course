ADC, Sampling, and Quantization

Understand how microcontrollers turn analog signals into digital measurements and what those numbers really mean.

Learning Objectives

By the end of this lesson, you should be able to:

  • Explain ADC resolution and quantization.
  • Distinguish sample rate from resolution and accuracy.
  • List the calibration and input-range checks required for trustworthy measurements.

An ADC converts a voltage into a number

An analog-to-digital converter (ADC) samples an input voltage and maps it to one of a finite set of digital codes. A nominal N-bit converter has up to 2ᴺ codes. More bits can provide finer code steps, but they do not automatically guarantee accuracy: noise, reference variation, input impedance, nonlinearity, calibration, and board-level interference all matter.

For an ideal N-bit ADC over a range from 0 V to a reference voltage Vref, a rough code step is Vref / 2ᴺ. Real datasheets may define endpoints and scaling differently, so treat this as an intuition rather than a substitute for the device specification.

Resolution is not accuracy

A display that reports 1.237 V may only be showing more digits, not a more trustworthy measurement. Accuracy depends on the whole measurement chain: sensor tolerance, analog circuitry, ADC behavior, reference stability, calibration, and the conversion formula. Effective noise-free resolution can be lower than the nominal bit width.

Sampling has a time dimension

Sampling once per minute and sampling a thousand times per second produce different views of a changing signal. A slow sample rate can miss brief events; a very high rate increases data volume and may waste energy. For a band-limited signal, sampling theory places constraints on the minimum sample rate needed to represent it without aliasing, and practical systems often require analog filtering before the ADC.

From raw code to a useful unit

Do not assume an ADC code is a temperature, light level, or battery percentage. The firmware needs the correct scale, reference behavior, sensor model, and calibration. On some MCU families, ADC readings are nonlinear or vary by chip; vendor calibration support may be necessary. Check the exact target's documentation and driver API.

Noise and source impedance

ADC input sampling circuitry briefly draws charge. A high-impedance source or unsuitable RC network can prevent the input from settling within the acquisition time. Layout, ground return, radio activity, supply noise, and sensor wiring can also affect readings. Filtering can reduce noise but introduces latency and may hide rapid changes.

Practical Lab

  1. Use a simulator or a documented ADC input on your exact board.
  2. Record the ADC resolution and supported input range from the official documentation.
  3. Take readings at several known safe input levels; never exceed the allowed pin voltage.
  4. Plot or tabulate raw code against the applied voltage.
  5. Repeat readings at a steady input and estimate variation. Separate observed noise from calibration error.
  6. Document how raw code is converted to volts and then to the physical quantity.

Expected result: An ADC record stating target, input range, resolution, sample conditions, raw readings, and the conversion/calibration assumptions.

Troubleshooting: Check that the input stays within the documented ADC range and distinguish quantization from accuracy or calibration error.

Common Pitfall

Equating more ADC bits with better measurement accuracy, or assuming an ADC input is safe for any voltage. Resolution, accuracy, sampling behavior, and electrical range are distinct.

Check Your Understanding

1. What does ADC resolution mean?

It describes the number of discrete output codes available; it does not by itself guarantee measurement accuracy.

2. What is aliasing?

When a signal is sampled too slowly to represent its changes correctly, higher-frequency behavior can appear as a misleading lower-frequency pattern.

3. Why must the exact MCU documentation be checked before using an ADC?

Input ranges, calibration, attenuation, nonlinearity, supported pins, and driver behavior vary by target and revision.

Key Takeaways

  • Explain ADC resolution and quantization.
  • Distinguish sample rate from resolution and accuracy.
  • List the calibration and input-range checks required for trustworthy measurements.
