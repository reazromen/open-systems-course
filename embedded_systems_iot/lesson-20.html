Logs, Backtraces, and Fault Diagnosis

Logs are observations, not automatically root causes. Include component, event, and relevant state without secrets; excessive logging can change timing. A backtrace lists execution frames that may lead to a failure and should be decoded with the matching ELF. Optimization or stack corruption can make traces incomplete. Classify memory faults, stack exhaustion, assertions, watchdogs, peripheral timeouts, and reset events. Reproduce, capture, form one hypothesis, change one variable, and repeat.

Learning Objectives

  • Capture and preserve logs, reset reasons, and crash backtraces.
  • Decode a backtrace with symbols from the exact firmware build.
  • Use a reproducible, one-variable-at-a-time fault investigation.

Practical Reasoning

Capture a complete crash log; symbolize a sample backtrace with the exact ELF; classify the likely fault; write a report with reproduction steps and next experiment.

Practical Lab

  1. Save the complete serial log and reset reason before changing code or resetting again.
  2. Reproduce the fault with a documented sequence and note the firmware revision and configuration.
  3. Decode the backtrace using the ELF and symbol files from that exact build.
  4. Form one hypothesis, change one variable, repeat the same test, and compare evidence.
  5. Expected result: a short fault report with reproduction steps, decoded evidence, likely cause, and the next experiment; if decoding fails, verify the ELF and build identity.

Common Pitfall

Do not change multiple variables before preserving logs and a reproducible case.

Check Your Understanding

1. What does a backtrace provide?

Execution frames that may lead to the failure.

2. Why is the ELF important?

It maps addresses to source using build-specific symbols.

3. What makes an experiment useful?

A reproducible test changing one variable and recording evidence.

Key Takeaways

  • Preserve the first failure before changing the system.
  • Decode traces with matching symbols and build metadata.
  • A useful diagnosis is reproducible and evidence-based.
